# 🌿 Explorers of Verdaneth

**Explorers of Verdaneth** is a full-fledged 2D indie **adventure-fantasy RPG** that blends **strategic, turn-based grid combat** with classic **top-down exploration** and **deep party management**.

Set in the rich, war-torn continent of **Verdaneth**, you’ll lead a growing band of explorers through a land divided by rebellion, noble oppression, and ancient secrets waiting to be unearthed.

---

## 🧭 Key Features

### 🗺️ Top-Down Exploration
- Navigate towns, dungeons, wilderness, and ruins in classic **Zelda-inspired 2D style**
- Solve environmental puzzles, uncover secrets, and interact with dynamic NPCs
- Discover a living world shaped by **class division, war, and political unrest**

### ⚔️ Tactical Grid Combat
- Engage in **Fire Emblem-style turn-based battles** on tactical grids
- Positioning, terrain, and unit synergy are key to survival
- Strategic depth with class types, elemental affinities, and map objectives

### 👥 Party Management
- Recruit, train, and evolve a roster of unique characters
- Each unit has distinct abilities, roles, and upgrade paths
- Build bonds, unlock support dialogues, and customize your squad’s tactics

### 💻 Built for Performance
- Designed with **clean code architecture and scalable systems**
- Optimized for **smooth performance on desktop platforms**
- Modular scene system: seamlessly transitions between overworld, exploration, and combat

---

## 🔧 Tech Stack

- **Engine:** Unity (C#)
- **Structure:** Modular scenes (Overworld → Exploration → Tactical Combat)
- **Data:** JSON-based save/load, flexible party and combat configuration
- **Rendering:** 2D sprite-based with custom shaders and UI
